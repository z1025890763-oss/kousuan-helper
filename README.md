# 小猿口算 PK 极速秒答助手（一加 ACE 5 专属配置版）

本工具专为**小猿搜题 / 小猿口算 PK 对战**设计，支持屏幕悬浮窗快捷控制、比大小（`>`、`<`、`=`）与加减四则运算毫秒级识别与极速作答。

---

## 📱 方案说明（首选：手机端独立运行）

推荐使用 **AutoX.js（免电脑、手机端独立运行）** 方案：
- 屏幕上方提供可拖动的**半透明悬浮窗控制面板**。
- 支持**一键开始/暂停**、**速度调节（最高 10 题/秒）**、**模式切换**与**答题计数**。
- 毫秒级 ROI 局部截屏 + 笔画路径快速下发，无需连接电脑。

---

## 🚀 手机端（一加 ACE 5 / ColorOS）安装与配置指南

### 第一步：下载并安装 AutoX.js
1. 在手机上下载并安装 **AutoX.js v6.x**（或 Auto.js 开源版本）。
2. 打开 AutoX.js 应用。

### 第二步：授予 ColorOS 必要权限（关键）
一加 ACE 5 运行 ColorOS 系统，为了保证 100ms 极速响应且不被后台查杀，需开启以下权限：
1. **无障碍权限 (Accessibility)**：
   - 手机设置 -> 其他设置 / 系统设置 -> 无障碍 -> 已安装的服务 -> 找到 `AutoX.js` 并开启。
2. **悬浮窗权限**：
   - 手机设置 -> 应用 -> 应用管理 -> AutoX.js -> 权限 / 悬浮窗 -> 允许在其他应用上层显示。
3. **后台保活与电量无限制**：
   - 长按 AutoX.js 图标 -> 应用信息 -> 耗电管理 -> 允许完全后台行为 / 允许自启动。
4. **截屏录屏授权**：
   - 首次启动脚本时，系统会弹出“AutoX.js 将开始截取您的屏幕内容”，勾选“不再提示”并点击“立即开始”。

### 第三步：导入并运行脚本
1. 将本项目中的 [`xiaoyuan_kousuan_helper.js`](file:///c:/Users/颜/Documents/antigravity/eager-shannon/xiaoyuan_kousuan_helper.js) 复制或发送到手机（如通过微信/QQ传输助手、数据线拷贝等）。
2. 在 AutoX.js 首页点击右上角 `+` 号 -> 导入脚本 -> 选择 `xiaoyuan_kousuan_helper.js`。
3. 点击脚本右侧的 ▶ **运行** 按钮，屏幕上即可出现悬浮窗面板。

---

## 🎮 悬浮窗功能与操作方式

| 按钮/区域 | 功能说明 |
| :--- | :--- |
| **标题栏** | 按住可自由拖动悬浮窗位置，显示当前累计完成题数（如 `[20题]`） |
| **[▶ 开始 / ⏸ 暂停]** | 一键启动/暂停秒答监听 |
| **[⚡ 极限] 测速档位** | 点击循环切换速度：<br>• **⚡ 极限 (10题/s)**：笔画耗时 25ms，间隔 15ms，秒解全场<br>• **🚀 极速 (5题/s)**：稳定连赢推荐<br>• **🎯 稳健 (2题/s)**：拟真手写速度<br>• **🐢 休闲 (1题/s)**：日常练习 |
| **[比大小 / 通用算术]** | 模式切换：<br>• **比大小模式**：专项秒写 `>`、`<`、`=`<br>• **通用算术模式**：支持 `+ - × ÷` 与多位数手写 |
| **[✕]** | 退出并销毁悬浮窗 |

## 💻 备用方案：电脑端 ADB 极速版（Python）

如果您喜欢连接电脑调试或录屏，我们还提供了 [`xiaoyuan_adb_fast.py`](file:///c:/Users/颜/Documents/antigravity/eager-shannon/xiaoyuan_adb_fast.py)：

2. 电脑端安装依赖：
   ```bash
   pip install rapidocr_onnxruntime opencv-python numpy
   ```
3. 运行脚本：
   ```bash
   python xiaoyuan_adb_fast.py
   ```
